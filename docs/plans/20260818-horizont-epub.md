# Go-утилита для сборки выпусков «Горизонта» в EPUB

## Overview

Создать CLI-утилиту `horizont-epub`, которая принимает URL выпуска, извлекает обложку, тематические блоки и материалы, скачивает тексты и изображения статей и формирует автономный EPUB 3 с вложенным содержанием.

Интерфейс:

```text
horizont-epub [-o output.epub] <issue-url>
```

Без `-o` имя формируется из последнего сегмента URL, например `horisont-n-82.epub`. Любая ошибка загрузки или разбора отменяет сборку без частичного EPUB.

## Context

- Исходный проект пуст; доступны только `index.html` с выпуском и `index.html.1` со статьёй.
- Выпуск: заголовок `.entry-title`, данные `.entry-content`, обложка перед заголовком «Содержание», блоки в `h4`, материалы в следующих абзацах.
- Статья: заголовок `.entry-title`, текст `.entry-content`; нужно удалить ссылку возврата, рекламу Jetpack, скрипты и блоки публикации.
- Файлы: `go.mod`, `go.sum`, `main.go`, `parser.go`, `fetch.go`, `epub.go`, соответствующие `*_test.go`, `testdata/`, `README.md`.
- Зависимости:
  - [goquery](https://github.com/PuerkitoBio/goquery) — разбор и изменение WordPress HTML.
  - [bluemonday](https://github.com/microcosm-cc/bluemonday) — allowlist-очистка HTML.
  - [go-epub](https://pkg.go.dev/github.com/go-shiori/go-epub) — EPUB 3, EPUB 2 TOC, обложка, CSS и изображения.
- Go 1.25+; проверка выполняется установленным Go 1.26.6.

## Development Approach

- **Testing approach**: Regular — реализация компонента, затем его unit/regression-тесты.
- Последовательная загрузка страниц без конкурентного обхода сайта.
- HTTP/HTTPS, тайм-аут 60 секунд, лимиты 16 MiB для HTML и 32 MiB для одного изображения.
- Поддерживаемые встроенные изображения: JPEG, PNG, GIF и SVG. Неизвестный формат завершает сборку с ошибкой.
- EPUB записывается во временный файл и публикуется только после полной успешной сборки.
- Каждый этап завершается запуском всех существующих тестов.
- **CRITICAL: every task MUST include new/updated tests**
- **CRITICAL: all tests must pass before starting next task**
